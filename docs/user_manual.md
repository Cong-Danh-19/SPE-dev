# Hướng dẫn Cài đặt & Sử dụng (User Manual)

## 1. Yêu cầu hệ thống
- Python >= 3.10
- Thư viện lõi `bkitevsim` đặt tại thư mục gốc dự án.

## 2. Các lệnh thực thi chính
- Cài đặt thư viện: `make install`
- Chạy kiểm thử Verification: `make test`
- Chạy toàn bộ thực nghiệm E1–E5: `make run-exp`
- Vẽ biểu đồ phân tích: `make plot`
- Đóng gói nộp bài: `make pack`
